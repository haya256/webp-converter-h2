# PNG → WebP 変換

ブラウザだけで完結するローカルPNG→WebP変換ツールです。サーバーへのアップロードは一切行わず、Canvas APIを使ってすべての変換をブラウザ内で処理します。

🔗 **公開ページ: https://haya256.github.io/webp-converter-h2/**

## 特徴

- サーバー送信なし・完全ローカル変換（Canvas API）
- 複数ファイルのドラッグ&ドロップ / クリック選択に対応
- 「高画質」「標準」「軽量」の3つの品質プリセットで同時変換
- 元画像とのサイズ比較（%表示）とファイルサイズ表示
- 変換結果をワンクリックでダウンロード
- ライト/ダークモード自動対応

## 使い方

1. [index.html](./index.html) をブラウザで開く
2. PNGファイルをドロップゾーンにドラッグ&ドロップ、またはクリックしてファイルを選択
3. 「高画質」「標準」「軽量」の3種類のWebP画像が自動生成される
4. サムネイルをクリックすると拡大表示、「保存」ボタンでダウンロード

## 技術構成

- 依存パッケージなし、ビルド不要の単一HTMLファイル
- 画像デコード・エンコードは `Canvas.toBlob()` (`image/webp`) を使用
